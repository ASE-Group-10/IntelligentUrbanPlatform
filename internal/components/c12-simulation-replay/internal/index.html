    Provided internal interfaces¶

    recordSimulationEvent(runId, record: RecordingRecord) → Result¶

    Caller: trusted isolated simulation recorder, never a public replay session. runId is a required UUID v4 matching record and event. Example: record. Its SyntheticDeliveryCompleted event from C12-fixture is deliberately synthetic, not a production event declaration. Real payloads use the original producer's schema; see events.yaml.

    Persist full ordered outcomes independent of coalesced city notifications. Sequence is contiguous/one-based per run; same eventId returns original receipt, conflicting ID/sequence fails. Receipt DTO fields remain unagreed; the model does not enforce cross-record ordering/durability. Failures: Invalid (wrong run/scope/payload), Forbidden, Conflict, Unavailable (no partial recording).

    advanceReplay(sessionId, expectedCursor) → Result¶

    Caller: trusted replay scheduler. sessionId: UUID v4, required; expectedCursor: nonnegative strict integer, required. Applies the next recorded outcome exactly once; completed at range end. Failures: Invalid, Forbidden, NotFound, Conflict, Unavailable. Interrupted recording reads pause without cursor advance. This is a provided scheduler boundary; checkpoint loading/reconstruction helpers are component implementation details and are not additional public contracts.

    Internal recording/checkpoint values¶

    RecordingRecord (required fields): runId (UUID v4), sequence (strict integer >=1), simulationTime (UTC timestamp), event (shared EventEnvelope from the same simulation run). Example: recording.

    Checkpoint (required fields): runId (UUID v4), cursor (strict integer >=0), simulationTime (UTC timestamp), stateRef (nonempty string, at most 200 characters), stateSha256 (64 lowercase hexadecimal characters). Example: checkpoint. These are internal values, not C01 endpoints.

    The shared envelope is defined by backend/app/shared/contracts.py; producer event payloads are referenced in events.yaml, never copied into the HTTP catalog. TimeRange/Indicator are reused from C11's Python module. C12's namespaced OpenAPI value schemas are exports of those same models for the aggregate catalog, not new metric formulas or producer event definitions.

    Recording, reproducibility and checkpoint semantics¶

    The manifest and checkpoint reference immutable objects. Fixture refs/hashes are placeholders, not verified real objects. Retain versioned scenario/configuration, generator version and deterministic inputs; seed alone does not establish reproducibility. Runtime must verify object integrity.

    Cursor is the last applied sequence, zero for initial state. A checkpoint is the state after its cursor. Apply full source outcomes by sequence even at equal timestamps. Coalesced CityStateUpdated notifications cannot replace a complete source recording. Validate sequence gaps, duplicate conflicts and checkpoint/range consistency at runtime; individual models only validate shape/run scope.

    Replay loads a checkpoint at/before the selected start and all essential outcomes through the selected range. Missing configuration, checkpoint or essential event makes that range unreconstructable; return CannotReplay and availableRanges. After a read interruption retain the last successful state/cursor; resume retries the next unread event exactly once.

    Timeline transport¶

    The C01 play/pause/resume/seek/stop state table and HTTP error mapping now belong to c12ControlReplay in openapi.yaml. Scheduler natural completion and read interruption still use the same recorded-state/cursor guarantees. Speed is presentation pacing only. Its >0 and <=16 bound needs C01 review; seek does not rerun today's planner. Stop/completion returns the existing frame; additional final-summary fields need a future agreed DTO.
