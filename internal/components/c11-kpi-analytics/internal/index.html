    Provided internal interfaces¶

    consumeOperationalEvent(event) → Result¶

    Callers: trusted operational-event adapters for C04/C05/C06/C08, with C10 outcome/record access to be agreed. Input is the producer-owned EventEnvelope: eventId, eventType, schemaVersion, producer, observedAt, emittedAt, correlationId, affected, scope, payload, plus optional causationId, entityVersions and simulation runId. See C06's shared envelope definition. Check producer identity, event type/version and authorised scope before processing.

    Atomically deduplicate eventId with the read-model update, preserve source/coverage provenance and return the same receipt on redelivery. Never send an operational command. Receipt fields and the producer subscription set remain unagreed; this format migration does not fabricate a DTO or declare subscriptions to events whose owners have not published contracts. events.yaml references the existing C06 definition as a proposed input, not an agreed metric formula.

    Failures: Invalid (unsupported envelope/payload/version), Forbidden (untrusted producer/scope), Conflict (incompatible duplicate), Unavailable (read-model/receipt store; no partial commit). Transient delivery retry policy remains an infrastructure agreement.

    Result semantics and unresolved metric definitions¶

    • Missing: null value, unavailable status and explicit reason, never zero.
    • A measured zero is valid only with observations. Usable indicators need a value and lastUpdated; no observations cannot produce a value.
    • observed cannot exceed eligible. available requires observed == eligible; incomplete coverage is partial. Excluded records are counted separately.
    • Estimates require versioned estimationBasis and are never labelled measured.
    • Trends use period-specific indicators with matching units/definition versions.
    • A refresh failure retains previous values and original lastUpdated, returns status: stale and failure. Without previous results return Unavailable; generatedAt is response time. Current sets cannot contain partial/missing items.
    • Initial families: delivery time, cost, congestion and environmental impact. Formulas, weights, rates, factors, denominators, freshness thresholds and exact source payloads are not approved. fixture-v1-not-approved, seconds/EUR and synthetic supporting records illustrate shape, not production calculation.
